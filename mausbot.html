01

MausBot là gì?

Dự án độc lập của Milind Soni và cộng đồng, trước đây mang tên OpenGrokBot. MausBot không phải một model AI mới; nó quản lý vòng đời và trải nghiệm sử dụng các agent engine hiện có. [1] [3]

ID

Bot

Danh tính lâu dài: tên, hướng dẫn, model, bộ nhớ, công cụ và thư mục làm việc.

TH

Thread

Cuộc hội thoại độc lập, có session provider, lịch sử, tiến trình và yêu cầu phê duyệt riêng.

EN

Agent engine

Thực thi suy luận và công cụ thông qua CLI hoặc runtime đã kết nối.

Ví dụ: Một nhóm gồm Manager, Developer dùng Codex và Reviewer dùng Claude có thể làm việc trên cùng mục tiêu nhưng duy trì từng thread riêng. Đây là mô hình minh họa, không phải cấu hình mặc định.

05

Một lượt thực thi

Ví dụ khái niệm về quy trình giao nhiệm vụ viết code và review. [6]

01 / REQUEST

Người dùng

Gửi mục tiêu cho Manager.

02 / DELEGATE

Manager

Giao nhiệm vụ cho Developer.

03 / EXECUTE

Developer

CLI sửa code, chạy test; xin quyền nếu cần.

04 / REPORT

Reviewer

Review độc lập; Manager tổng hợp kết quả.

Concurrency: Tài liệu nêu tối đa 3 direct threads mỗi bot, tính cả thread chờ phê duyệt. Giới hạn này không thay thế lock tài nguyên hoặc cơ chế điều phối task toàn hệ thống. [7]
06

Triển khai & self-hosting

Đề xuất thử nghiệm headless trên môi trường cô lập trước khi tích hợp vào Debian hiện tại. Các lệnh bên dưới là tham khảo; trang này không thực thi lệnh. [8]

Chuẩn bị runtime

Node.js 24+, pnpm nếu build source, ít nhất một CLI đã đăng nhập với đúng service user. Kiểm tra phiên bản trước.

node --version
codex --version
claude --version
opencode --version

Chạy thử với Tailscale

Chọn phiên bản đã kiểm tra nguồn phát hành; dùng pairing link để truy cập. Không mở harness thẳng ra Internet.

npx openmausbot@0.1.165 serve --tailscale
Package npm ở phiên bản này chưa được xác minh riêng; kiểm tra trên registry trước khi chạy.

Build để nghiên cứu mã nguồn

Chạy từng lệnh dev trong terminal riêng. Desktop shell chỉ cần khi nghiên cứu Electron.

git clone https://github.com/milind-soni/OpenMausBot
cd OpenMausBot
pnpm install
pnpm dev:server
# terminal khác:
pnpm dev
# tùy chọn, terminal khác:
pnpm dev:desktop
Giới hạn: Ubuntu là nền tảng Linux được nêu rõ trong tài liệu. Debian, quyền desktop và khả năng sử dụng một số backend cần kiểm thử riêng. Không chạy bằng root; chưa có kiểm thử thực tế trên máy của bạn.
07

Bảo mật và giới hạn

Full access mặc định

Bot mới có thể chạy chế độ đầy đủ quyền. Chuyển sang Ask for approval, dùng service user và thư mục thử nghiệm. Một số thay đổi cấu hình bot không có approval bổ sung.

Local-first ≠ offline

Model bên ngoài, Composio, Boat hoặc voice service có thể xử lý dữ liệu theo cấu hình.

Giới hạn nền tảng

Khả năng computer use thay đổi theo OS và bản phát hành; đặc biệt cần kiểm tra Linux và Wayland.

Giấy phép

Core Apache 2.0. Thư mục enterprise có giấy phép riêng; cần kiểm tra trước khi tái sử dụng hoặc cung cấp dịch vụ.

Không xem approval UI là sandbox. Cần xác thực ranh giới quyền ở OS, engine và container; bảo vệ token pairing, lưu trữ và secrets. [9]
