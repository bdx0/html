08 / Implementation

Quy tắc sử dụng

Nên

Dùng token thay vì màu tùy ý; một primary action mỗi vùng; nội dung quan trọng có nhãn rõ; keyboard focus luôn hiển thị; table có cuộn riêng; giữ dữ liệu khi đổi layout.

Tránh

Dùng pastel làm chữ trên nền trắng không đủ tương phản; hero chiếm quá nhiều diện tích; ép mọi thiết bị dùng ba cột; dùng prototype thay nghiệp vụ thật.

CSS token contract & responsive breakpoints
Desktop >1180px: 3 cột; tablet 761–1180px: 2 cột; mobile ≤760px: 1 cột. Các layout demo tự đổi theo kích thước mô phỏng.
