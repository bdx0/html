01 / FOUNDATIONS

Static web có thể trở thành ứng dụng đầy đủ

GitHub Pages phục vụ HTML, CSS và JavaScript qua HTTPS. Trình duyệt thực thi logic, gọi backend, giữ dữ liệu cục bộ và thiết lập kết nối realtime. Static không đồng nghĩa với dữ liệu tĩnh.

Điều kiện để gọi API

API truy cập được từ trình duyệt; HTTPS; CORS đúng origin khi khác nguồn; xác thực và phân quyền phía server; xử lý preflight OPTIONS.

Không giới hạn ở REST

Trình duyệt hỗ trợ yêu cầu HTTP, WebSocket, SSE, WebRTC và các API khác tùy nền tảng. Không thể mở socket TCP/UDP tùy ý như ứng dụng native.

const res = await fetch("https://api.example.com/tasks", {
  headers: { Authorization: "Bearer " + accessToken }
});
if (!res.ok) throw new Error("HTTP " + res.status);
const tasks = await res.json();

accessToken là token của người dùng được cấp sau khi đăng nhập, không phải secret API key nhúng trong HTML.

03 / CLOUDFLARE

Public Tunnel và Private Tunnel

Public hostname

Không cần mở port inbound tại origin khi cloudflared kết nối outbound. Truy cập bằng browser, có thể dùng Access hoặc xác thực ứng dụng. Hỗ trợ HTTP, HTTPS, WSS, SSE; SSH/TCP qua hostname thường cần client cloudflared hoặc phương thức truy cập phù hợp.

Private network route

Thiết bị được cấp quyền và định tuyến qua Cloudflare One Client. Hỗ trợ workload mạng riêng như truyền file lớn và backup. Không phải dịch vụ công khai cho người dùng bất kỳ; vẫn chịu điều khoản Zero Trust và giới hạn kỹ thuật.

Phân biệt lớp vận chuyển: cloudflared kết nối tới Cloudflare bằng QUIC hoặc HTTP/2. Đây là kết nối hạ tầng Tunnel, không phải quyền cho JavaScript mở UDP hoặc QUIC tùy ý tới Debian.
04 / LIMITS & POLICY

Băng thông, streaming và file lớn

Cloudflare không công bố quota GB/tháng chung cố định riêng cho Public Tunnel trong các tài liệu được đối chiếu. Điều đó không đảm bảo băng thông vô hạn hoặc miễn phí cho mọi loại lưu lượng. Dung lượng ổ cứng origin cũng không phải quota lưu trữ Cloudflare.

Giới hạnFreeProBusiness
HTTP request body tối đa100 MB100 MB200 MB
File cache tối đa512 MB512 MB512 MB
Băng thông/tháng của TunnelKhông công bố một hạn mức số GB chung
Dung lượng lưu tại DebianPhụ thuộc ổ cứng, không phải dịch vụ hosting của Tunnel

Giới hạn upload và cache là của lớp HTTP/CDN; không phải tổng dung lượng download hoặc tổng dữ liệu của một kết nối WSS. Timeout của proxy và origin vẫn cần xử lý riêng.

Quy định nội dung: Public hostname qua Tunnel vẫn đi qua CDN. Cloudflare có thể hạn chế việc dùng CDN tự phục vụ để phân phối video hoặc tỷ lệ lớn nội dung không phải HTML (như file dung lượng lớn) nếu không sử dụng dịch vụ phù hợp. Không có ngưỡng TB/tháng an toàn được công bố. Đổi HTTP sang WSS hoặc tắt cache không phải ngoại lệ chính sách đã được xác nhận.

Upload file lớn

Chia file bằng resumable/chunked upload, kiểm tra hash, số thứ tự, giới hạn từng request và quyền truy cập. Việc chia nhỏ không làm thay đổi chính sách phân phối công cộng.

Video / NAS

Dùng Private Tunnel cho truy cập cá nhân; R2 cho phân phối file hợp lệ; Stream hoặc hạ tầng media phù hợp cho video công khai; WebRTC cho tương tác realtime.

05 / WEBRTC

PeerJS, STUN, TURN và đường truyền P2P

SIGNALING

PeerJS / PeerServer

PeerJS là thư viện JS bọc WebRTC; PeerServer hỗ trợ trao đổi offer/answer và ICE. Có máy chủ miễn phí dùng chung, không nên coi là SLA production.

DISCOVERY

STUN

Hỗ trợ phát hiện địa chỉ/port public do NAT ánh xạ. Không trung chuyển media. Có thể sử dụng STUN công cộng của Cloudflare.

RELAY

TURN

Chuyển tiếp dữ liệu khi kết nối trực tiếp không khả thi. Tốn băng thông; cần credential ngắn hạn và theo dõi chi phí.

Signaling

Hai bên trao đổi SDP offer/answer và ICE candidates qua WSS hoặc PeerServer.

ICE kiểm tra kết nối

Ưu tiên đường phù hợp, trực tiếp nếu điều kiện mạng cho phép; nếu không, thử candidate relay TURN.

Truyền dữ liệu

Media tracks cho gọi thoại/video, DataChannel cho tin nhắn và file. File lớn cần chunk, bufferedAmount/backpressure, tiến độ và checksum.

Chat offline, nhận cuộc gọi khi web đóng, push notification, tài khoản và lịch sử đồng bộ cần dịch vụ bổ sung. PWA không đảm bảo kết nối media nền trên mọi hệ điều hành.

06 / COST MODEL

Ước tính chi phí Cloudflare TURN

STUN của Cloudflare miễn phí. TURN và SFU dùng chung 1.000 GB egress miễn phí mỗi tháng, sau đó 0,05 USD/GB. TURN tính dữ liệu từ edge tới client (gồm overhead); không tính phí hai lần cho đường TURN ↔ SFU/Stream WHIP/WHEP đủ điều kiện.

Mô phỏng lưu lượng cuộc gọi 1–1

TURN egress / 30 ngày—
Chi phí sau free tier—

Giả định 2 luồng bitrate bằng nhau được relay, 30 ngày, GB thập phân, chưa tính header/overhead, SFU hoặc dịch vụ khác. Nếu chỉ một endpoint nhận dữ liệu qua TURN thì số liệu khác. Đây không phải báo giá hay giới hạn tài khoản.

Phương án khác: tự triển khai coturn trên máy chủ có địa chỉ và port phù hợp; phí phụ thuộc VPS, IP public, traffic và quản trị. Không đưa secret TURN hoặc key tạo credential vào static web.

07 / SECURITY

Static web không mặc định kém bảo mật

PUBLIC

Có thể công khai

HTML/CSS/JS, URL API, logic hiển thị, public key hoặc public client ID. Coi mọi mã frontend là có thể đọc, sửa và gọi lại từ bên ngoài.

SERVER ONLY

Phải giữ ở backend

Mật khẩu DB, private key, secret API key, TURN key, quyền quản trị, kiểm tra quyền nghiệp vụ và dữ liệu không được phép truy xuất.

  • HTTPS/WSS; kiểm tra access token hoặc phiên đăng nhập ở mọi API/RPC.
  • Phân quyền theo tài khoản, tài nguyên và hành động; không tin cậy ID do client gửi.
  • CORS đúng origin; xác minh Origin cho WebSocket. CORS không chặn cURL hoặc thay thế xác thực.
  • Validate dữ liệu, rate limit, chống replay khi cần, giới hạn kích thước message; audit log và token ngắn hạn.
  • Chống XSS, tránh secret trong bundle/local storage, cân nhắc cookie HttpOnly/SameSite và CSRF theo mô hình origin.
  • WebRTC mã hóa đường truyền bằng DTLS/SRTP; xác thực peer/signaling để ngăn giả mạo. Không mặc định cung cấp xác minh danh tính đầu cuối.
  • P2P có thể bộc lộ địa chỉ mạng; relay-only giảm lộ IP trực tiếp nhưng tăng chi phí.
08 / SYSTEM DESIGN

Kiến trúc Hybrid P2P cho Debian

Nhu cầuLựa chọn ưu tiên
Quản lý hồ sơ, CRUDHTTPS REST qua Tunnel
AI streamingSSE hoặc WebSocket
Chat / thiết bị IoTWSS hoặc MQTT over WSS; WebRTC nếu cần P2P
Call / camera / remote desktopWebRTC + STUN/TURN; SFU cho nhiều người
NAS cá nhân / backupPrivate network route + WARP; HTTPS hoặc native protocol
File giữa peerWebRTC DataChannel, kiểm soát tốc độ và khôi phục tải
Video VOD công khaiCloudflare Stream hoặc hạ tầng media chuyên dụng. WebRTC không phải mặc định tối ưu cho VOD.

Lộ trình triển khai

Control plane

API auth/authorization và WSS gateway trên Debian, public hostname qua Tunnel.

Thử nghiệm P2P

Tạo 2 peer, kiểm tra chat/call và getStats() để phân biệt direct với relay trên Wi-Fi, 4G/5G, mạng CGNAT.

Truyền file và media

Chunk, retry, checksum, quota theo người dùng. Cấp TURN credential giới hạn từ server.

Đánh giá production

Đo tỉ lệ relay, egress, latency, tải CPU, quyền truy cập; dùng sản phẩm chuyên biệt nếu cần phân phối nội dung công khai.
